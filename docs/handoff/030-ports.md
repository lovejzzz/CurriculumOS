## The reference companion rule

The AI coder building the new repo gets CourseMapper checked out read-only beside it. Standing instruction: **when a spec here is ambiguous, read the prototype's implementation AND its pinning tests before deciding** — the tests encode why the behavior exists. If prototype behavior contradicts this kit, the kit wins, and the discrepancy gets noted in the new repo's decision log.
